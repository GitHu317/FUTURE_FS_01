Task 1: Personal Professional Portfolio Website

🚀 Project Overview
This is a full-stack personal portfolio application designed to showcase professional skills and projects. It features a modern, interactive frontend and a robust backend system for handling user inquiries.

✨ Key Features
Interactive 3D Visuals: A custom-built HTML5 Canvas particle system providing a dynamic background.

Full-Stack Contact Form: A functional "Contact Me" section that captures user data and triggers email notifications.

Lead Management: Integrated database storage for all contact form submissions.

SEO Optimized: Semantic HTML structure for better search engine visibility.

🛠️ Tech Stack
Frontend

Framework: React 18 (Vite) 

Styling: Custom CSS3 Animations

Backend

Environment: Node.js & Express.js 


Database: MySQL (Local/Cloud) 


Email Service: Resend API 

⚙️ Local Configuration
To run this project locally, you must configure your environment variables:

Create a .env file in the server/ directory.

Add the following configurations:


DB_HOST: Your database host (e.g., localhost).


DB_USER: Your database username.


DB_PASS: Your database password.


DB_NAME: Your database name.


RESEND_API_KEY: Your unique Resend API key.
